01 · 工作流程

从 Issue 到可审阅的补丁

这是 Agent 已实现的工具流程；下方任务浏览器展示的是离线参考案例，不是模型执行回放。

01

接收 Issue

读取固定版本的仓库和明确的行为要求。

02

创建临时副本

在隔离的工作目录里操作，保留原始任务文件。

03

查找并编辑

使用受限的文件工具定位代码并做文本修改。

04

运行两组测试

公开测试与独立验收都通过，才算任务成功。

05

保存结果

输出补丁、执行轨迹和报告，供人检查。
